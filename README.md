# Random Joke Generator

A beautiful and interactive joke generator web application powered by the JokeAPI.

## Features

- 🎭 Generate random jokes with a single click
- 😂 Support for both single-line and two-part jokes
- 📋 Copy jokes to clipboard with one button
- 🎨 Modern, responsive design with gradient UI
- ⚡ Real-time loading states
- 📱 Fully mobile-optimized

## How to Use

1. Open `joke-generator.html` in your web browser
2. Click "Get Joke" to fetch a random joke
3. Click "Copy Joke" to copy the joke text to your clipboard
4. Enjoy the jokes!

## API Used

This project uses the [JokeAPI](https://jokeapi.dev/) - a free API for generating jokes.

## Live Demo

Just open `joke-generator.html` in your browser!

## Technologies

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (ES6+)
- JokeAPI (External API)
